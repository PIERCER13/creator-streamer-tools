# Creator & Streamer Toolkit

QR Code customizado, compressor de imagens em lote e overlay para OBS

## Funcionalidades

- **Seções principais**: Gerador de QR Code, Redimensionador & Compressor em Lote, Configurador de Overlay para OBS
- **Ações disponíveis**: QR Code, Compressor de Imagens, Overlay OBS, Baixar PNG, Baixar Tudo (.zip), Copiar, + Salvar Preset
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8083`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8083`.
